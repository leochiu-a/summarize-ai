隱私權政策

Summarize AI Buddy Chrome Extension ・ 最後更新：2026-07-29

Summarize AI Buddy（以下稱「本擴充功能」）是一個只在 kkday.com 網域上運作、 在網頁右下角顯示互動角色的 Chrome 擴充功能，用瀏覽器內建的 on-device AI 協助你摘要頁面、 理解商品、潤飾與翻譯評論、判斷值不值得買。此外它還透過 WebMCP 標準提供兩支唯讀 查詢工具，讓你自己選用的 AI agent 可以直接取得結構化的商品資訊。我們非常重視你的隱私，本頁說明 本擴充功能會存取哪些資料、資料如何被處理，以及資料會不會被傳送出去。

一句話總結

小夥伴的 AI 功能（摘要、商品分析、評論潤飾與翻譯）都在你的裝置本機完成， 網頁內容不會被傳送到我們或任何第三方的伺服器。我們沒有後端伺服器， 也不會蒐集、分析或出售你的任何資料。

WebMCP 查詢工具是不一樣的路徑，請分開理解：當你的 AI agent 呼叫這些工具時， 工具回傳的商品資訊會交給那個 agent。若你使用的是雲端 AI 服務，那些資訊就會離開你的 裝置，依該服務自己的隱私權政策被處理。我們不經手、也無法控制那段流程。

本擴充功能會存取什麼

  • 目前分頁的網頁內容：本擴充功能會讀取當前頁面可見的文字內容 （或用 Readability 演算法抽取的文章正文），做為 AI 功能的輸入。依你所在的頁面與操作而定， 可能包含：頁面正文（頁面摘要）、商品說明（商品重點摘要與購買建議）、其他旅客留下的評論 （一鍵翻譯），以及你自己正在撰寫中的評論文字（評論潤飾）。
  • 頁面的 Nuxt 狀態：在商品頁上，WebMCP 查詢工具會讀取頁面自己的 window.__NUXT__ 變數，從裡面取得商品與方案的識別碼（pkg_oid、 item_oid）。這些是頁面本來就已經載入的公開資料，取得後只用來向 kkday.com 查詢 方案可訂性，不含任何個人資料。

小夥伴的 AI 功能如何運算

小夥伴的功能使用 Chrome 瀏覽器內建、由 Gemini Nano 等模型驅動的 on-device AI API： Summarizer（頁面摘要）、 Prompt（商品摘要與購買建議）、 Rewriter（評論潤飾）、Translator 與 LanguageDetector（評論翻譯）。這些模型直接在你的 裝置上運算，頁面內容與產生的結果全程只存在於你的瀏覽器裡，不會經過網路傳送到任何伺服器 ——包含我們自己的伺服器在內，因為我們根本沒有經營任何伺服器。

⚠️ 這一節只涵蓋小夥伴自己的功能。下一節的 WebMCP 查詢工具完全沒有用到內建 AI， 資料流向也不一樣。

WebMCP 查詢工具（實驗性）

本擴充功能透過 WebMCP 標準（document.modelContext），在 kkday.com 頁面上註冊兩支唯讀查詢工具， 讓你自己選用並連上的 AI agent 可以直接呼叫，不必自行解析頁面：

  • 商品搜尋：依關鍵字、評分與評論數門檻回傳候選商品，附評分、價格區間與最早可出發日。
  • 方案可訂性查詢：查某個日期各方案訂不訂得到，以及剩餘數量。

這兩支工具都是唯讀的：它們只查詢與回報資訊，不會修改頁面內容、 不會變更你的帳號或購物車狀態，也沒有任何下單、結帳或付款的功能。

資料會流向哪裡（請務必理解這一點）

這些工具本身不會把資料傳給我們——我們沒有伺服器。但當你的 AI agent 呼叫工具時， 回傳的商品資訊會交給那個 agent 處理。如果你用的是雲端 AI 服務（例如 Chrome 內建的 Gemini、或你自己接上的其他 MCP client），那些資訊就會離開你的裝置，依該服務自己的 隱私權政策被傳送與處理。

我們不是傳送方，也無法控制或檢視那段流程——但這條管道是本擴充功能刻意提供的，所以我們有責任 明確告知你。工具回傳的內容只包含 kkday.com 頁面上的公開商品資訊，不含你的個人資料、 訂單紀錄或帳號資訊。

這是實驗性功能：WebMCP 目前仍在標準制定階段，需要 Chrome 開啟對應的實驗旗標才會生效。 在未開啟的瀏覽器上，這一層完全不會運作，也不會有任何資料流動。

⚠️ 目前這些工具在 kkday.com 頁面上是自動註冊的，設定頁還沒有提供關閉開關。 但要注意：註冊本身不會傳送任何資料——只有在你的 agent 主動呼叫工具時才會查詢與回傳。 未開啟 Chrome 實驗旗標、或沒有連上任何 agent 的情況下，這一層不會有任何作用。

本擴充功能發出的網路請求

小夥伴的 AI 功能完全不需要連網（模型下載由 Chrome 自己處理）。但上述 WebMCP 查詢工具需要向 kkday.com 查資料，因此會發出以下同源的唯讀 GET 請求：

  • ajax_get_product_list——商品搜尋，帶你的搜尋關鍵字。這是 kkday 搜尋結果頁自己在用的同一支 API。
  • fetch-items-data——方案可訂性與剩餘數量。這是 kkday 商品頁日曆自己在用的同一支 API。

這些請求只會送到 kkday.com，不會送到我們或任何第三方（我們沒有伺服器、 也沒有使用任何分析或追蹤服務）。請求會沿用你在 kkday.com 上既有的登入狀態 （same-origin），跟你自己在瀏覽器上瀏覽 kkday 時發出的請求性質相同。

本機儲存了什麼

為了讓體驗更好，本擴充功能會用 Chrome 的 storage.local API 把以下資料存在你自己的裝置上：

  • 使用者設定：你在設定頁選擇的語氣與摘要類型、小夥伴的總開關狀態，以及你選擇「在這頁停用」的頁面清單（只存頁面路徑，不含 query 參數，也不是瀏覽紀錄——只有你自己按下停用的那幾頁才會被記下來）。
  • 結果快取：短時間內重新開啟同一頁面時，直接使用先前產生的結果，避免重複運算。包含頁面摘要（依網址，保留 30 分鐘）與商品重點摘要（依商品 id，保留 24 小時）；快取內容包含網址／商品 id 與產生的文字。評論翻譯與潤飾的結果不進本機快取。

這些資料只存在你自己的瀏覽器設定檔中，會跟著 Chrome 帳號同步（如果你有開啟 Chrome 同步）， 但不會被傳送給我們或任何第三方。移除本擴充功能時，這些資料會一併被 Chrome 清除。

我們不會做的事

  • 不會蒐集你的瀏覽紀錄、頁面內容或個人資料，也不會把它們傳送到我們的伺服器（我們沒有伺服器）
  • 不使用任何分析、追蹤或廣告相關的第三方服務（沒有 Google Analytics、沒有像素、沒有 SDK）
  • 不會將資料出售或分享給第三方以換取利益
  • 不會在背景存取與前述功能無關的頁面資料
  • 不會代你下單、結帳或付款——本擴充功能完全沒有這類功能，WebMCP 工具也全部是唯讀的
  • 不會代你送出評論——潤飾與翻譯的結果要不要採用、什麼時候送出，都由你自己決定

⚠️ 唯一的例外要講明白：如上一節所述，當你的 AI agent 呼叫 WebMCP 工具時，回傳的商品資訊會進入 那個 agent。這不是我們「傳送」資料，而是你指定的 agent 主動查詢——但結果上資料確實可能離開你的 裝置，所以不適用「完全不會有任何資料流出」這種說法。

本擴充功能只在 kkday.com 上運作

本擴充功能只會在 kkday.com（含其子網域）的頁面上運作，在其他網站上完全不會被載入、 也不會有任何權限或存取行為。這個存取權限只用來四件事： (1) 在 kkday.com 頁面右下角顯示小夥伴角色的介面、 (2) 讀取當前頁面的文字內容做為小夥伴 AI 功能的輸入（在你的裝置本機運算）、 (3) 註冊前述兩支唯讀 WebMCP 查詢工具，並在你的 agent 呼叫時向 kkday.com 查詢商品與可訂性資料、 (4) 在你打開設定頁時讀取當前分頁的網址，好讓「在這頁停用」知道是哪一頁（只在設定頁開啟時讀、只讀 kkday.com 的分頁；我們沒有申請範圍更大的 tabs 權限，所以其他網站的分頁網址對本擴充功能是不可見的）。 除此之外不會做任何其他用途。
